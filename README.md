Концепция InvestBattle
Жанр: Мультиплеерный экономический симулятор с элементами PvP-баттла.

Суть: Игроки получают стартовый капитал и за ограниченное время раундов покупают/продают акции. Цены меняются в реальном времени. Побеждает тот, у кого больше денег к финалу.

Откуда деньги?
Игровая валюта — монеты (💵). Их можно:

Получать за победы

Тратить на вход в комнаты со ставками

Тратить на разблокировку режимов (например, Фрилансер за 5000 💵)

Основные режимы
Режим	Описание
🤖 Тренировка с ботом	Соло-игра против AI. Можно настроить капитал, раунды, время.
👥 Комнаты	Игроки создают/подключаются по коду. Есть открытые и закрытые. Можно ставить ставку в монетах.
💼 Фрилансер	Хардкорный режим: старт с $100, акции дёшевы и волатильны. Вход стоит 5000 💵 и действует 7 дней. Рейтинг по прибыли за неделю.
Типы комнат
Жёсткая — все с одним капиталом и раундами, без голосований.

Произвольная — каждый входит со своим капиталом, временем и раундами; параметры усредняются.

Механика раунда
Показывается новость про компанию (например, «Apple выпускает новый чип»).

Цена актива начинает меняться.

Игрок решает: купить (ставка на рост) или NO (пропустить/зафиксироваться).

Все, кто нажал NO, синхронизируются — раунд завершается досрочно.

Финальная фаза: 90 секунд, чтобы продать всё. Кто продал — фиксирует прибыль.

Социальные фичи
Друзья — добавление, заявки, приглашения в комнаты.

Чат внутри лобби комнаты.

Торговля — в PvP можно предложить другому игроку купить его акции.

Уникальность
Режим призрака: админы/модераторы могут невидимо наблюдать за любой игрой (не влияя на счётчик игроков).

Читы для админов: прогноз исхода цены (включается в админ-панели).

Телеграм-интеграция: игра работает как WebApp внутри Telegram, поддерживает аватары и никнеймы из профиля.

Монетизация (внутриигровая)
Ставки в комнатах.

Платный вход в режим Фрилансер.

Админская панель для выдачи/изъятия монет (для организаторов турниров).
